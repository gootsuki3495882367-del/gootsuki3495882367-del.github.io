Q1 · Transport layer

Video streaming over TCP and UDP

Python socket server and player that stream a 30 fps video in both protocols, tested with emulated delay and packet loss and analysed in Wireshark.

Q2 · Application layer

This website + network analysis

Deployed with GitHub Pages. Studied with nslookup, ping, tracert and a packet capture of DNS, the TCP handshake and TLS.

Q3 · MapReduce model

MapReduce in pure Python

Map, combine, partition, shuffle & sort and reduce implemented with the standard library and parallel worker processes.

Q4 · Big-data frameworks

Word count: Hadoop vs Spark

The same word count in Hadoop Streaming and PySpark on 3 MB to 190 MB of text, comparing code, execution and running time.

Q5 · Spark MLlib

Income prediction with MLlib

A full ML pipeline on the UCI Adult data: cleaning, encoding, logistic regression and tree models, evaluated with AUC and F1.
