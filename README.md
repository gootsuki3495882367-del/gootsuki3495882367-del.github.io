# CSI205TC student page

Static personal page for CSI205TC Networking and Distributed Computing (Coursework 1, Question 2),
served by GitHub Pages.

* `index.html` – page structure
* `style.css` – layout, light/dark theme, responsive design
* `main.js` – theme switch, project filter and a network inspector based on the browser's
  Navigation Timing API (DNS, TCP, TLS, waiting time and download time of this page)
